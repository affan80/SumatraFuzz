# Security policy

Test malformed PDFs only inside disposable, low-privilege Windows x64 environments. Treat every seed, crash dump, log and result as untrusted; do not automatically open crashing documents on personal machines.

Do not disclose unpatched exploit files or private findings through public GitHub issues. Use GitHub private vulnerability reporting if enabled, or coordinate a private reporting channel with the maintainer. Reproduce and triage crashes before making vulnerability or CVE claims. No security response SLA is promised.
